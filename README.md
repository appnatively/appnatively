## Installation

1. Clone Github Repository

   ```sh
   git clone https://github.com/appnatively/appnatively.git
   ```

2. Install composer dependencies
   ```sh
   composer setup
   ```

3. Install npm dependencies (Node v20.10.x)
   ```sh
   pnpm install
   ```

4. Compile Scripts
   ```sh
   pnpm start
   ```

4. Build plugin
   ```sh
   pnpm build
   ```
